## Effects 디렉토리

`effects` 디렉토리는 약한 결합과 관련된 코드 및 로직을 저장하기 위한 곳입니다. 패키지에 다음과 같은 특징이 있는 경우 `effects` 디렉토리에 배치하는 것이 좋습니다:

- **상태 관리**: `pinia` 상태 관리 프레임워크를 사용하고 사이드 이펙트(비동기 작업, API 호출 등)를 처리하는 부분이 포함된 경우.
- **사용자 환경설정**: `@vben-core/preferences`를 사용하여 사용자 환경설정을 처리하고, 로컬 스토리지 또는 브라우저 캐시 로직(예: `localStorage` 사용)이 포함된 경우.
- **내비게이션 및 라우팅**: 내비게이션, 페이지 이동 등의 시나리오를 처리하고 라우팅 변경 로직을 관리해야 하는 경우.
- **컴포넌트 라이브러리 의존성**: 특정 컴포넌트 라이브러리와 밀접하게 결합되어 있거나 대규모 저장소에 의존하는 부분이 포함된 경우.

관련 코드를 `effects` 디렉토리로 분류하면 프로젝트 구조를 더 명확하게 만들 수 있으며 유지보수와 확장이 용이해집니다.
