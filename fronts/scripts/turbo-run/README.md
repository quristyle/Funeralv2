# @vben/turbo-run

`turbo-run`은 여러 패키지에서 명령을 병렬로 실행할 수 있게 해주는 명령줄 도구입니다. 대화형 인터페이스를 제공하여 명령을 실행할 패키지를 선택할 수 있습니다.

## 주요 기능

- 🚀 실행할 패키지 대화형 선택
- 📦 monorepo 프로젝트 구조 지원
- 🔍 사용 가능한 명령 자동 감지
- 🎯 대상 패키지 정밀 필터링

## 설치

```bash
pnpm add -D @vben/turbo-run
```

## 사용 방법

기본 구문:

```bash
turbo-run [script]
```

예를 들어, `dev` 명령을 실행하려는 경우:

```bash
turbo-run dev
```

도구가 `dev` 명령이 있는 패키지를 자동으로 감지하고, 실행할 패키지를 선택할 수 있는 대화형 인터페이스를 제공합니다.

## 예시

프로젝트에 다음과 같은 패키지가 있다고 가정해 보겠습니다:

- `@vben/app`
- `@vben/admin`
- `@vben/website`

다음을 실행하면:

```bash
turbo-run dev
```

도구가 수행하는 작업:

1. `dev` 명령이 있는 패키지 감지
2. 대화형 선택 인터페이스 표시
3. 명령을 실행할 패키지 선택
4. `pnpm --filter`를 사용하여 선택한 패키지에서 명령 실행

## 주의 사항

- 프로젝트에서 pnpm을 패키지 관리자로 사용하는지 확인하세요.
- 대상 패키지의 `package.json`에 해당 스크립트 명령이 정의되어 있는지 확인하세요.
- 이 도구는 monorepo 프로젝트의 루트 디렉터리에서 실행해야 합니다.
