# 작업 계획서: AI 채팅 사이드바 너비 로컬 저장소(localStorage) 영속화 구현

## 1) 문제 요약
* **현상**: 사용자가 마우스 드래그로 AI 채팅 사이드바의 너비를 조절하더라도, 페이지를 새로고침하면 너비 상태가 초기 기본값인 384px로 초기화되어 매번 다시 조절해야 하는 불편함이 있습니다.
* **과제**: 브라우저의 `localStorage`를 활용하여 사용자가 최종 조절한 너비를 기기 브라우저 세션에 저장하고, 새로고침 시 이 값을 로드하여 마지막 상태를 지속하도록 개선합니다.

---

## 2) 설계 요약
* **수정 대상 파일**: 
  * `fronts/packages/effects/layouts/src/basic/layout.vue`
* **설계 상세**:
  * **저장 키(Key)**: `vben_ai_chat_sidebar_width`
  * **초기화 로직**:
    * 컴포넌트 마운트 전 반응형 변수 `aiChatWidth` 선언 시, `localStorage.getItem`을 시도하여 유효한 숫자 형식 값이 존재할 경우 해당 너비로 초기 세팅하고, 없을 경우에만 기본값 `384`를 적용합니다.
  * **저장 트리거**:
    * 마우스 드래그가 완전히 끝나는 시점인 `stopResize()`가 실행될 때 최종 반영된 `aiChatWidth.value` 값을 `localStorage`에 기록하여 드래그 중 실시간 I/O 발생으로 인한 성능 하락(화면 랙)을 방지합니다.

---

## 3) 구현 계획
* **Task 1: layout.vue 마운트 초기값 및 저장 로직 구현**
  * `localStorage`에서 마지막 설정된 너비를 읽는 안전한 초기값 반환 로직을 추가합니다.
  * `stopResize` 이벤트 핸들러 내에 `localStorage.setItem` 로직을 삽입합니다.
* **Task 2: 컴파일 및 빌드 테스트**
  * `@vben/layouts` 번들 빌드를 수행하여 무결성을 검증합니다.

---

## 4) 자가 코드 리뷰 계획
* `localStorage` 파싱 도중 발생할 수 있는 에러(Null, NaN 등)를 처리하여 널 세이프티 가드를 견고하게 처리했는지 확인합니다.
* 드래그 중인 `mousemove` 단계에서는 로컬 저장소 쓰기를 실행하지 않음을 확인하여 렌더링 부하를 배제합니다.
