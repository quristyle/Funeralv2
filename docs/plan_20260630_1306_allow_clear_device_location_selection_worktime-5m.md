# 구현 계획서: 장비 위치 선택(층/호실) 삭제(Clear) 기능 추가

- **작성일시**: 2026-06-30 13:06
- **예상 소요 시간**: 5분

---

## 1. 문제 요약
장비 상세 관리 화면(`device-management-tab.vue`)에서 장비 소속 위치를 '특정 호실'에서 '상위 층 소속' 또는 '건물 소속'으로 재배치(이동)할 수 있도록, 호실 및 층 선택 `BizSelect` 컴포넌트에 지우기(`allow-clear`) 기능을 적용합니다.

---

## 2. 디자인 요약
- **UI/UX 개선**:
  - 층 선택 및 호실 선택 `BizSelect` 콤보박스에 `allow-clear` 속성을 활성화합니다.
  - 사용자가 선택박스 오른쪽의 'X' 아이콘을 눌러 바인딩된 `floorId` 또는 `roomId` 값을 제거(지우기)할 수 있게 합니다.

---

## 3. 구현 계획
- **Step 1: UI 컴포넌트 속성 반영**
  - `device-management-tab.vue` 내 층(`floor`) 및 호실(`room`) `BizSelect` 컴포넌트에 `allow-clear` 속성 추가.
