# 주석 정리 — 규칙과 진행 방법

전체 353,612줄 가운데 주석이 102,260줄(28.9%)이다. 대부분이 **지금 코드를
읽는 데 필요 없는 변경 이력**이라 걷어 낸다.

이 문서는 **AI 실행기에게 주는 지시문의 정본**이다. 모듈마다 다른 기준으로
깎이면 정리가 아니라 또 다른 어지러움이라, 규칙을 여기 한 곳에 둔다.

## 무엇을 남기나

**코드를 보고는 알 수 없는 것만 남긴다.** 한두 줄이면 족하다.

남길 것 — 되밟기 쉬운 함정, 겉보기와 다른 까닭, 고르지 않은 쪽의 이유:

- 「`@bind-Text:event="oninput"` 을 걸면 회로가 끊긴다 — 빌드는 통과한다」
- 「`@key` 가 없으면 가운데 한 장이 빠질 때 맨 끝이 지워진다」
- 「`CommPopup` 에 `ChildContent` 가 없어 그냥 넣으면 열리는 순간 500 이 난다」
- 「이 경계 767px 는 CSS 와 같아야 한다」

걷을 것:

- **날짜 박힌 변경 이력** — `(2026-10-15)`, 「2026-09-18 에 바꿨다」
- **지금 없는 모양을 설명하는 글** — 「한동안 …이었다」, 「예전에는」,
  「전에는 …였는데」, 「…로 흉내 냈다」
- **같은 이야기의 두 번째 사본** — 머리말과 본문에 겹쳐 적힌 것
- **코드가 이미 말하는 것** — `private int Count => …` 위의 「개수」
- **쓰는 법 예제** — 부르는 자리가 저장소에 이미 있으면 그쪽이 정본이다
- **설계 서사** — 「왜 팝업이 아니라 좌우 분할인가」 같은 긴 글. 길면
  `docs/` 로 옮기고 주석에는 그 경로만 남긴다

## 갈래마다 다른 규칙

| 갈래 | 줄 수 | 규칙 |
|---|---|---|
| `.razor` 의 `@* *@` | 16.7k | 위 기준 그대로. 머리말은 10줄 안쪽 |
| `.cs` 의 `///` | 62.5k | **`<summary>` 는 남기고 `<remarks>`·`<para>` 서사를 걷는다** |
| `.cs` 의 `//` | 12.8k | 위 기준 그대로 |
| `.css` 의 `/* */` | 8.8k | **구역 표지는 남긴다**(파일이 만 줄이라 길잡이다) |
| `.dart` | 1.2k | 이미 날씬하다. 손대지 않는다 |

`///` 를 가르는 까닭: `<summary>` 는 IntelliSense 에 떠서 **부르는 쪽의 개발
경험 그 자체**이고, 부피는 거의 다 그 아래 `<remarks>` 에 있다. `<summary>`
가 한 줄을 넘으면 줄이되 **지우지는 않는다.**

## 반드시 지킬 것

**코드는 한 줄도 바뀌지 않는다.** 주석 정리에 기능 변경을 묻혀 보내지
않는다 — 섞이면 리뷰가 불가능해진다. 고칠 것을 발견하면 따로 올린다.

기계로 확인한다:

```
python3 scripts/comment-guard.py origin/main
```

주석을 걷어낸 양쪽을 맞춰 보고 **코드가 달라지면 실패**한다. 커밋 둘을
견주려면 인자를 둘 준다(`comment-guard.py <기준> <대상>`).

### CSS 는 한 가지를 더 본다

CSS 주석은 **겹치지 않는다.** 블록 주석 안에 `/* */` 가 또 있으면 안쪽
`*/` 가 주석을 먼저 닫고 **그 뒤 몇 줄이 값으로 읽히다 죽는다**
(web/CLAUDE.md 의 같은 항목). 주석을 대량으로 손댈 때 정확히 터지는
종류라, CSS 는 규칙 개수가 그대로인지 함께 센다.

```
grep -c '^\s*[.#@a-zA-Z].*{\s*$' <파일>      # 전후가 같아야 한다
```

## 마지막에 할 것 — 되돌아가지 않게

정리가 **다 끝난 뒤에** 아키텍처 테스트로 규칙을 건다. 지금 걸면 1,806
파일이 한꺼번에 걸려 CI 가 그 자리에서 빨개진다.

선례가 있다 — `web/tests/JSini.Web.Architecture.Tests/RazorCommentTests.cs`
가 이미 주석 규칙 하나를 테스트로 막고 있다. 같은 틀로 「주석 블록이 N줄을
넘지 않는다」와 「주석에 날짜를 적지 않는다」를 건다.

`CLAUDE.md` 의 규칙 줄에도 한 줄 더한다 — 지금은 「한국어로 쓴다」뿐이다.
