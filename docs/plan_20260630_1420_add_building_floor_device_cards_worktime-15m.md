## 1. 문제 요약
특정 호실이 아닌 '건물 자체' 혹은 '층 전체'에 공용 서비스용으로 할당된 DID, 키오스크 등의 IoT 장비들이 존재합니다. 이 공용 장비들을 빈소 현황 화면([building-section.vue](file:///C:/Funeralv2/fronts/apps/funeralv2/src/views/building/status/modules/building-section.vue))의 알맞은 건물 및 층 섹션 영역 내에 공용 장비 카드로 추가하여 시인성을 극대화합니다.

---

## 2. 디자인 요약
- **데이터 공급 연동**:
  - `use-status-data.ts`에서 API로 긁어온 전체 장비 목록 `devices`를 ref 상태로 외부에 제공합니다.
  - `status/index.vue`에서 이 `devices` 목록을 받아 `BuildingSection` 컴포넌트로 전달합니다.
- **건물 공용 장비 카드**:
  - 조건: `roomId`와 `floorId`가 전부 존재하지 않는 해당 건물 장비.
  - 건물 요약 요율 배너 하단에 "건물 공용 서비스 장비" 전용 가로형 카드 패널을 렌더링합니다.
- **층 공용 장비 카드**:
  - 조건: `roomId`가 존재하지 않고 해당 층 `floorId`에 엮여 있는 장비.
  - 층별 호실 카드 그리드 영역 맨 첫 번째 자리에 `[층 공용 장비]` 전용 카드 형태로 삽입하여 레이아웃의 균형을 유지합니다.
