# JSINI 브랜드 키트

작성: 2026-08-26
용도: 회사 소개 사이트(`www.jsini.co.kr`) · 문서 · 명함 · 제안서

이 폴더의 SVG 는 손으로 고치지 않는다. [generate.py](generate.py) 가 좌표를 계산해서 전부 다시 쓴다.

```bash
python docs/brand/generate.py
```

고칠 것이 있으면 `generate.py` 의 글리프 좌표나 배치 상수를 고치고 다시 돌린다.
결과를 눈으로 확인할 때는 [preview.html](preview.html) 을 브라우저로 연다.

## 1. 무엇으로 만들어졌나

레터폼을 직접 그렸다. 폰트를 쓰지 않았으므로 저작권 문제도, 폰트 파일 배포 문제도 없다.

| 규칙 | 값 |
|---|---|
| 기준 단위 | 캡 높이 30 · 스템 6 (5:1) |
| 각도 | 수직 · 수평 · 사선. 곡선은 없다 |
| 블레이드 컷 | J 스템 상단만, 정확히 45° · 6 유닛 |
| 워드마크 트래킹 | 10 유닛 (캡 높이의 33%) |
| 심볼 스케일 | 기준 단위의 2배 (캡 60 · 스템 12) |

블레이드 컷이 이 브랜드의 서명이다. 심볼의 J 와 워드마크의 J 가 같은 각도로 잘려 있어서,
둘을 떼어 놓아도 한 집안으로 읽힌다. 다른 글자에는 쓰지 않는다.

### 심볼의 겹침이 4 유닛인 이유

J 의 스템과 S 의 좌측 스템은 같은 자리를 지난다. 겹침을 크게 주면 1색 변형에서
J 실루엣을 따라 두르는 녹아웃 키라인이 S 의 좌측 스템을 완전히 먹어 버리고,
그러면 S 의 상단바가 중간바에서 떨어져 나가 글자가 무너진다.

겹침 4 유닛 · 키라인 2 유닛이면 S 의 좌측 스템에 6 유닛(절반)이 남는다.
이 수치는 바꾸지 않는다. 바꿔야 한다면 `generate.py` 의 `SYM_S_X` 계산과
`symbol-mono` 를 같이 검산해야 한다.

## 2. 색

액센트 색은 두지 않는다. 강조는 색이 아니라 대비로 낸다 — 흰 바탕에 잉크 블록.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| Ink | `#0A0A0A` | 심볼의 J · 워드마크 · 어두운 면 |
| Graphite | `#1C1C1E` | 어두운 면 위의 한 단계 밝은 면 · 테두리 |
| Steel | `#6E6E73` | 심볼의 S · 보조 텍스트 · 헤어라인 |
| Mist | `#D2D2D7` | 녹아웃 심볼의 S · 구분선 |
| Paper | `#FFFFFF` | 밝은 면 · 녹아웃 글자 |

정사각이 필요한 자리는 심볼을 쓰지 않는다. 심볼은 84×60(1.4:1) 이라 정사각에 넣으면
좌우가 빈다. 파비콘 · 앱 아이콘 · SNS 프로필은 `favicon.svg` — 블레이드 J 한 자로 축약한 것 — 을 쓴다.

## 4. 조합 규칙

```
가로 조합    [심볼] ──24── JSINI      심볼 높이 60, 워드마크 캡 30 (절반)
세로 조합    [심볼]                    간격 18, 워드마크 폭에 맞춰 중앙 정렬
             JSINI
```

간격과 크기 비율은 파일에 고정되어 있다. 심볼과 워드마크를 각각 옮기거나 따로 키우지 않는다.
둘을 다시 조합할 일이 있으면 파일을 그대로 쓴다.

### 보호 여백

심볼 스템 두께 1개분 = **12 유닛** (심볼 높이의 20%). 로고 사방으로 이만큼은 아무것도 두지 않는다.
`construction.svg` 의 점선이 이 경계다.

### 최소 사용 크기

| 자산 | 최소 폭 |
|---|---|
| `favicon.svg` | 16px |
| `symbol-duotone` / `symbol-knockout` | 24px |
| `symbol-mono` | 64px — 키라인이 2 유닛이라 이보다 작으면 사라진다 |
| `wordmark` | 96px |
| `logo-vertical` | 96px |
| `logo-horizontal` | 120px |

## 5. 금지

- 기울이기 · 회전 · 좌우 반전 · 비율 변경
- 그림자 · 글로우 · 그라디언트 · 테두리 추가
- 위 5색 밖의 색. 특히 심볼의 S 를 Steel 이 아닌 회색으로 바꾸는 것
- **2톤 심볼을 한 색으로 눌러 쓰기.** J 와 S 가 한 덩어리로 붙는다. 1색이 필요하면 `symbol-mono` 를 쓴다
- `symbol-mono` · `logo-horizontal-mono` 를 흰색이 아닌 배경에 쓰기 (키라인이 흰색으로 고정되어 있다)
- 심볼과 워드마크 사이 간격을 바꾸거나 각각 다른 비율로 키우기
- 사진 위에 로고를 직접 올리기. Ink 블록을 깔고 녹아웃 변형을 쓴다
- 래스터로 내보낸 파일을 원본 삼아 확대하기

## 6. 상승 조각 모티프

심볼이 아니다. 심볼 자리에 쓰지 않는다.
히어로 모션 배경 · 섹션 구분 · 통계 블록 · 다운로드 카드의 hover 상태처럼
페이지 전체에 같은 리듬을 반복하기 위한 보조 그래픽이다.

조각의 기울기(shear 22 : 높이)와 명도 4단계(Mist → Steel → Graphite → Ink)를 유지한다.
개수는 4개를 기본으로 하되 공간에 따라 줄인다. 늘리지는 않는다.

## 7. 래스터가 필요할 때

파비콘은 SVG 를 그대로 쓴다(요즘 브라우저는 받는다).
PNG 가 반드시 필요한 곳은 `apple-touch-icon`(180×180) 과 구형 안드로이드뿐이다.

변환 도구는 아직 저장소에 없다. 필요해지면 sharp 나 ImageMagick 중 하나를 골라
`generate.py` 뒤에 붙이는 스크립트로 추가한다. 손으로 내보낸 PNG 를 커밋하지 않는다 —
원본이 바뀌었을 때 같이 바뀌지 않는다.
