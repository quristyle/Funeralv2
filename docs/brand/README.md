# JSINI 브랜드 키트

작성: 2026-08-26
용도: 회사 소개 사이트(`www.jsini.co.kr`) · 업무 포털(`admin.jsini.co.kr`) · 문서 · 명함 · 제안서

이 폴더의 SVG 는 손으로 고치지 않는다. [generate.py](generate.py) 가 좌표를 계산해서 전부 다시 쓴다.

```bash
python docs/brand/generate.py
```

고칠 것이 있으면 `generate.py` 의 글리프 좌표나 배치 상수를 고치고 다시 돌린다.
결과를 눈으로 확인할 때는 [preview.html](preview.html) 을 브라우저로 연다.

## 1. 무엇으로 만들어졌나

레터폼을 직접 그렸다. 폰트를 쓰지 않았으므로 저작권 문제도, 폰트 파일 배포 문제도 없다.

| 규칙 | 값 |
|---|---|
| 기준 단위 | 캡 높이 30 · 스템 6 (5:1) |
| 각도 | 수직 · 수평 · 사선. 곡선은 없다 |
| 블레이드 컷 | J 스템 상단만, 정확히 45° · 6 유닛 |
| 워드마크 트래킹 | 10 유닛 (캡 높이의 33%) |
| 심볼 스케일 | 기준 단위의 2배 (캡 60 · 스템 12) |

블레이드 컷이 이 브랜드의 서명이다. 심볼의 J 와 워드마크의 J 가 같은 각도로 잘려 있어서,
둘을 떼어 놓아도 한 집안으로 읽힌다. 다른 글자에는 쓰지 않는다.

### 심볼의 겹침이 4 유닛인 이유

J 의 스템과 S 의 좌측 스템은 같은 자리를 지난다. 겹침을 크게 주면 1색 변형에서
J 실루엣을 따라 두르는 녹아웃 키라인이 S 의 좌측 스템을 완전히 먹어 버리고,
그러면 S 의 상단바가 중간바에서 떨어져 나가 글자가 무너진다.

겹침 4 유닛 · 키라인 2 유닛이면 S 의 좌측 스템에 6 유닛(절반)이 남는다.
이 수치는 바꾸지 않는다. 바꿔야 한다면 `generate.py` 의 `SYM_S_X` 계산과
`symbol-mono` 를 같이 검산해야 한다.

## 2. 색

액센트 색은 두지 않는다. 강조는 색이 아니라 대비로 낸다 — 흰 바탕에 잉크 블록.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| Ink | `#0A0A0A` | 심볼의 J · 워드마크 · 어두운 면 |
| Graphite | `#1C1C1E` | 어두운 면 위의 한 단계 밝은 면 · 테두리 |
| Steel | `#6E6E73` | 심볼의 S · 보조 텍스트 · 헤어라인 |
| Mist | `#D2D2D7` | 녹아웃 심볼의 S · 구분선 |
| Paper | `#FFFFFF` | 밝은 면 · 녹아웃 글자 |

정사각이 필요한 자리는 심볼을 쓰지 않는다. 심볼은 84×60(1.4:1) 이라 정사각에 넣으면
좌우가 빈다. 블레이드 J 한 자로 축약한 것을 쓰는데, 두 가지가 있고 쓰는 자리가 다르다.

| | 모양 | 쓰는 자리 |
|---|---|---|
| `favicon.svg` | 잉크 블록에 J 를 음각 | **혼자 서는 자리** — 브라우저 탭, 앱 아이콘, SNS 프로필 |
| `app-icon.svg` | 배경 없이 J 글자만 | **이름 글자 옆에 서는 자리** — UI 머리글, 사이드바 |

블록형을 이름 옆에 두면 32px 짜리 잉크 사각형이 글자와 무게가 맞지 않고, 어두운 테마에서는
흰 블록이 되어 더 튄다. 반대로 글자만 있는 것을 파비콘에 쓰면 16px 에서 존재감이 사라진다.
업무 포털이 이 규칙대로 쓴다 — 파비콘은 블록, 사이드바는 글자
(`apps/jsini-portal/src/preferences.ts`).

## 4. 조합 규칙

```
가로 조합    [심볼] ──24── JSINI      심볼 높이 60, 워드마크 캡 30 (절반)
세로 조합    [심볼]                    간격 18, 워드마크 폭에 맞춰 중앙 정렬
             JSINI
```

간격과 크기 비율은 파일에 고정되어 있다. 심볼과 워드마크를 각각 옮기거나 따로 키우지 않는다.
둘을 다시 조합할 일이 있으면 파일을 그대로 쓴다.

### 보호 여백

심볼 스템 두께 1개분 = **12 유닛** (심볼 높이의 20%). 로고 사방으로 이만큼은 아무것도 두지 않는다.
`construction.svg` 의 점선이 이 경계다.

### 최소 사용 크기

| 자산 | 최소 폭 |
|---|---|
| `favicon.svg` | 16px |
| `symbol-duotone` / `symbol-knockout` | 24px |
| `symbol-mono` | 64px — 키라인이 2 유닛이라 이보다 작으면 사라진다 |
| `wordmark` | 96px |
| `logo-vertical` | 96px |
| `logo-horizontal` | 120px |
| `app-icon` | 20px — 글자 옆에 서는 것이라 이보다 작으면 획이 뭉갠다 |

## 5. 금지

- 기울이기 · 회전 · 좌우 반전 · 비율 변경
- 그림자 · 글로우 · 그라디언트 · 테두리 추가
- 위 5색 밖의 색. 특히 심볼의 S 를 Steel 이 아닌 회색으로 바꾸는 것
- **2톤 심볼을 한 색으로 눌러 쓰기.** J 와 S 가 한 덩어리로 붙는다. 1색이 필요하면 `symbol-mono` 를 쓴다
- `symbol-mono` · `logo-horizontal-mono` 를 흰색이 아닌 배경에 쓰기 (키라인이 흰색으로 고정되어 있다)
- 심볼과 워드마크 사이 간격을 바꾸거나 각각 다른 비율로 키우기
- 사진 위에 로고를 직접 올리기. Ink 블록을 깔고 녹아웃 변형을 쓴다
- 래스터로 내보낸 파일을 원본 삼아 확대하기

## 6. 상승 조각 모티프

심볼이 아니다. 심볼 자리에 쓰지 않는다.
히어로 모션 배경 · 섹션 구분 · 통계 블록 · 다운로드 카드의 hover 상태처럼
페이지 전체에 같은 리듬을 반복하기 위한 보조 그래픽이다.

조각의 기울기(shear 22 : 높이)와 명도 4단계(Mist → Steel → Graphite → Ink)를 유지한다.
개수는 4개를 기본으로 하되 공간에 따라 줄인다. 늘리지는 않는다.

### 기다림 표시도 이 모티프로 한다 — `loader-shards.svg`

**심볼을 굴리지 않는다.** 위 5절이 기울이기·회전·비율 변경을 금지한다. 로딩 표시는 마크를
계속 찌그러뜨리며 돌리는 일이라, 정체성 마크는 애초에 대상이 아니다.

상승 조각은 원래 "같은 리듬을 반복하는 보조 그래픽" 으로 둔 것이라 여기에 그대로 맞는다.
움직임은 조각이 차례로 솟았다 내려앉는 것이다 — 물결이 왼쪽에서 오른쪽으로 지나가면서도
**오른쪽으로 갈수록 높은 실루엣**은 유지된다. 그래야 정지한 모티프와 같은 것으로 읽힌다.

| | 값 |
|---|---|
| 주기 | 1.1초 `ease-in-out` |
| 조각별 지연 | 0 · 0.12 · 0.24 · 0.36초 |
| 진폭 | `scaleY` 0.55 ↔ 1 (바닥 기준) |
| 색 | `currentColor` + 명도 4단계 — 밝은/어두운 테마를 파일 하나로 받는다 |

`prefers-reduced-motion: reduce` 면 **멈춘 그림**을 보여 준다. 움직임이 필요한 표시가 아니라,
움직임은 거들 뿐이다.

업무 포털이 두 자리에 쓴다.

```
apps/jsini-portal/loading.html                     앱 첫 로딩 스플래시 (가로 조합 + 로더)
packages/@core/ui-kit/shadcn-ui/.../spinner.vue    화면 전환 · v-loading · iframe 대기
```

## 7. 래스터 — `favicon.ico`

요즘 브라우저는 SVG 파비콘을 받는다. `.ico` 는 그것을 못 읽는 옛 브라우저용이다.
두 앱 모두 SVG 를 먼저 선언하고 `.ico` 를 대체로 둔다.

`favicon.ico` 도 **`generate.py` 가 만든다.** SVG 를 변환하지 않고 **같은 좌표에서 다시
그린다** — 변환기를 쓰면 도구가 하나 더 늘고, 이 모양은 다각형 둘이라 직접 그리는 편이
오히려 정확하다. 16 · 32 · 48 · 64 · 128 · 256px 여섯 벌이 한 파일에 들어간다.

Pillow 가 필요하다. 없으면 `.ico` 만 건너뛰고 SVG 는 그대로 만들어진다.

```bash
pip install pillow
python docs/brand/generate.py
```

안티에일리어싱은 8배로 그린 뒤 LANCZOS 로 줄여서 얻는다. 16px 에서 J 의 스템이 2px 이
채 안 되므로, 계단이 그대로 보이면 글자가 아니라 얼룩으로 읽힌다.

아직 없는 것은 `apple-touch-icon`(180×180 PNG) 뿐이다. 필요해지면 같은 방식으로
`generate.py` 에 한 줄 더한다. **손으로 내보낸 래스터를 커밋하지 않는다** —
원본이 바뀌었을 때 같이 바뀌지 않는다.

## 8. 어디에 복사되어 있나

원본은 이 폴더다. 각 앱의 `public/brand/` 는 **복사본**이라, 원본을 고치면
`generate.py` 를 돌린 뒤 다시 복사해야 한다.

```
docs/brand/                              원본 (generate.py 가 만든다)
fronts/apps/jsini-site/public/brand/     favicon · logo-horizontal · og-image
fronts/apps/jsini-site/public/favicon.ico
fronts/apps/jsini-portal/public/brand/   favicon · logo-horizontal(+knockout) · app-icon(+knockout)
fronts/apps/jsini-portal/public/favicon.ico
```

**앱에는 그 앱이 실제로 쓰는 것만 복사한다.** 정적 빌드라 `public/` 에 둔 것은 쓰지 않아도
그대로 배포에 실린다. 새로 쓸 자산이 생기면 그때 하나만 더 복사한다.

소개 사이트의 로고는 파일을 받아 오지 않고 `components/brand-logo.vue` 가 좌표를
인라인해 그린다(밝은/어두운 배경 전환과 첫 화면 요청 절약). 그래서 녹아웃 파일이 없다.
