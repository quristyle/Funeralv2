# VXE Table 그리드 데이터 렌더링 가이드
---

## 1. 뱃지(Badge) 형태의 시각적 렌더링 규칙
VXE Grid 테이블에 Boolean 값(`true`/`false`) 또는 특정 상태/구분 코드값을 표현할 때는, 날것의 문자열 텍스트를 노출하는 대신 **안트 디자인(Ant Design Vue)의 `Tag` 컴포넌트**를 사용하여 명칭을 시각적 뱃지 형태로 표현해야 합니다.

### 권장하는 디자인 대응
* **Boolean 값 (예: 활성화 여부, 계층구조 여부)**:
  * `true` ➔ 파란색/초록색 뱃지 (예: `'계층형'`, `'활성'`)
  * `false` ➔ 회색/기본색 뱃지 (예: `'단일형'`, `'비활성'`)
* **상태 코드값 (예: 사용 여부, 진행 상태)**:
  * 정상/사용 ➔ 초록색 뱃지 (예: `'사용'`)
  * 중지/미사용 ➔ 빨간색 뱃지 (예: `'미사용'`)

---

## 2. Slots 기반 커스텀 렌더링 구현 및 타입 안정성 확보
타입스크립트 엄격 모드(`vue-tsc --noEmit`) 상에서 `cellRender.content` 속성에 함수를 바인딩하면 컴파일 에러(`TS2322`)가 발생합니다.  
따라서 반드시 **Slots 패턴**(`slots.default`)과 Vue의 `h()` 렌더 함수를 결합하여 구조를 정의해야 합니다.

### 구현 예시

```typescript
import { h } from 'vue';
import { Tag } from 'ant-design-vue';
import type { VxeGridProps } from '@vben/plugins/vxe-table';

export const gridOptions: VxeGridProps<any> = {
  columns: [
    { type: 'seq', width: 50 },
    
    // 1) Boolean 형태 (예: 계층구조 여부)
    { 
      field: 'isHierarchical', 
      title: '계층구조', 
      width: 100,
      slots: {
        default: ({ row }) => {
          return h(
            Tag,
            { color: row.isHierarchical ? 'blue' : 'default' },
            { default: () => (row.isHierarchical ? '계층형' : '단일형') }
          );
        }
      }
    },
    
    // 2) 코드값 형태 (예: 사용 상태)
    {
      field: 'status',
      title: '상태',
      width: 80,
      slots: {
        default: ({ row }) => {
          return h(
            Tag,
            { color: row.status === 1 ? 'green' : 'red' },
            { default: () => (row.status === 1 ? '사용' : '미사용') }
          );
        }
      }
    }
  ]
};
```
